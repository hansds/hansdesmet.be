# hansdesmet.be

> Static website for hansdesmet.be, powered by Nuxt 3

## 🏗️ Build Setup

```bash
# install dependencies
$ npm install

# serve with hot reload at localhost:3000
$ npm run dev

# build for production and launch server
$ npm run build
$ npm run preview

# generate static project
$ npm run generate
```

## 🚀 Deploy

Committing or merging into `master` will result in a deploy to production. Submitting a merge request to `master` automatically generates a preview deploy on Netlify.

## Node

This repo requires Node 18+ (recommended: Node 20).
